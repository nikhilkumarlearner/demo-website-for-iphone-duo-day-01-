# 📱 iPhone Duo — Product Demo Website

A modern, responsive iPhone product showcase website built using **HTML5 and CSS3 only**. This project features a clean layout, stylish design, and an Apple-inspired product presentation.

## ✨ Features

- 🎨 Modern and minimal UI
- 📱 iPhone product showcase
- 💻 Responsive layout for different screen sizes
- 🌈 Smooth CSS transitions and hover effects
- 🖼️ Product images and stylish typography
- ⚡ Lightweight and fast-loading
- 🧩 Built without JavaScript or external frameworks

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations, and responsiveness

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/nikhilkumarlearner/demo-website-for-iphone-duo-day-o1-.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No installation or additional dependencies are required.
